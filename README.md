# ESP32 PM2.5 检测仪 🌫️

用 ESP32 + PMS5003 自制的 PM2.5 检测仪。手机或电脑打开网页，就能看到**实时读数**和**过去 24 小时的趋势曲线**。

零基础也能做，接线只要 4 根，不需要安装任何额外的库。

## ✨ 功能

- 实时显示 PM1.0、PM2.5、PM10（单位 μg/m³）
- PM2.5 按空气质量等级变色（优 / 良 / 轻度污染 / 中度污染 / 重度污染 / 严重污染）
- 过去 24 小时 PM2.5 曲线，背景按等级分色
- 24 小时最高、最低、平均值
- 通过 `http://air.local` 访问，路由器重启也不用重新找 IP

## 📦 材料清单

| 物品 | 说明 |
|---|---|
| PMS5003 激光粉尘传感器 | **建议买带转接板和连接线的**。原装排线间距只有 1.27mm，很难直接接 |
| ESP32 开发板 | ESP32-WROOM-32 开发板（如 ESP32 DevKit） |
| 母对母杜邦线 | 4 根 |
| USB 数据线 | 必须能传数据，有些线只能充电 |
| 5V 电源 | 手机充电头或充电宝 |

## 🔌 接线

| PMS5003 | ESP32 |
|---|---|
| VCC | VIN（5V） |
| GND | GND |
| TX | D16（有的板子印 RX2） |
| RX | D17（有的板子印 TX2） |

> ⚠️ VCC 必须接 **VIN（5V）**。接 3.3V 的话风扇转不起来。
>
> PMS5003 的 SET、RESET 等其他引脚不用接。

如果没有转接板，PMS5003 的 8 根线顺序为：

| 序号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 功能 | VCC | GND | SET | RX | TX | RESET | 空 | 空 |

## 💻 安装步骤

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)
2. 打开 **开发板管理器**，搜索 `esp32`，安装 **esp32 by Espressif Systems**
3. 打开本仓库里的 `pm25_monitor/pm25_monitor.ino`
4. 修改代码开头的 WiFi 名和密码（**只支持 2.4GHz WiFi**）：
```cpp
   const char* WIFI_SSID = "你的WiFi名";
   const char* WIFI_PASS = "你的WiFi密码";
```
5. **工具 → 开发板** 选 `ESP32 Dev Module`
6. **工具 → 端口** 选 `usbserial` 或 `wchusbserial` 开头的那个
7. 点击 **上传**
8. 打开 **串口监视器**，波特率选 `115200`，会看到：
```
   ✅ 已连接，浏览器打开：http://192.168.x.x
   ✅ 也可以用：http://air.local
```
9. 手机连接**同一个 WiFi**，浏览器打开 `http://air.local` 🎉

> 部分安卓手机不支持 `.local` 地址，请使用串口里显示的 IP 地址。

## 🛠️ 常见问题

| 问题 | 解决方法 |
|---|---|
| 上传失败：`Unable to verify flash chip connection` | **工具 → Upload Speed** 改成 `115200` |
| 上传失败：`port is busy or doesn't exist` | 重新在 **工具 → 端口** 选择；拔插一次看新出现的是哪个 |
| 端口列表里没有 ESP32 | 换一根能传数据的 USB 线；CH340 芯片的板子可能需要安装驱动 |
| Mac 编译报错：`bad CPU type in executable` | 苹果芯片的 Mac 需要安装 Rosetta，在终端运行：`softwareupdate --install-rosetta --agree-to-license` |
| 串口提示"完全没收到" | 先听 PMS5003 风扇转不转。不转检查 VCC、GND；在转的话，把 D16、D17 两根线对调 |
| 串口提示"收到了数据但解析失败" | 检查 GND 是否接好、杜邦线是否松动 |
| WiFi 连接失败 | 检查 WiFi 名和密码，确认是 2.4GHz 网络 |
| 曲线一直显示"数据收集中" | 正常现象，每 5 分钟记录一个点，开机约 10 分钟后出现曲线 |

## 💡 使用提示

- 开机后传感器需要**预热约 30 秒**，前 30 秒的数据不会记录到曲线里
- 曲线数据保存在内存中，**断电或重启后会清空**
- PMS5003 是低成本传感器，**湿度高时读数会偏高**，适合观察变化趋势。可以和官方空气质量数据对比参考
- 传感器的进风口和出风口不要被遮挡，也不要正对风扇或空调出风口

## ⚙️ 可调参数

在代码开头可以修改：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `HOST_NAME` | `"air"` | 访问地址 `http://air.local` 中的名字 |
| `SAMPLE_SEC` | `300` | 每隔多少秒记录一个点 |
| `HISTORY_LEN` | `288` | 最多记录多少个点（288 × 5 分钟 = 24 小时） |

> 想看一周的曲线，把 `SAMPLE_SEC` 改成 `1800`（30 分钟），288 个点就能覆盖 6 天。注意网页上的横轴固定显示 24 小时，需要同时修改网页代码。

## 📄 说明

代码中的空气质量等级按中国 PM2.5 浓度分级粗略划分，仅供参考。
